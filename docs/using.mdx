Run `tea`. That's it. The menu stays open across actions.

Passwordless setup is optional. The client asks before the first privileged change; macOS handles the hidden password prompt. Only do this on an account you trust.

<Frame>
  <img src="/images/shutdown.png" alt="Schedule a shutdown" />
</Frame>

When a newer release exists, the client shows a line under the menu; press `u` to update. After an update, open the client. If the helper is stale, it offers repair.

## Scripts

| Command | Effect |
| --- | --- |
| `tea on` | Keep this Mac awake |
| `tea off` | Restore the sleep setting tea owns |
| `tea status` | Print awake, power, and shutdown state |
| `tea shutdown after 2h` | One shutdown (`m` / `h` / `d`, 10 minutes–7 days) |
| `tea shutdown cancel` | Cancel only that event |
| `tea auth register` | Install the narrow passwordless helper |
| `tea auth unregister` | Remove it |
| `tea update` | Install the latest release (`--check` only reports it) |
| `tea version` | Print the version |

`tea status` and `tea auth status` never ask for a password.
