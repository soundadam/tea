```sh
brew trust --tap soundadam/tap
brew install --cask soundadam/tap/tea
tea
```

That's the client. It stays open.

macOS 13 or later; direct downloads are on [GitHub Releases](https://github.com/soundadam/tea/releases). [Using tea](/using) has the script commands. [Safety](/safety) before you close a lid.
